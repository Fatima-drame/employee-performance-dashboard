## Project Overview

The Employee Performance Dataset was analysed in Power BI to evaluate employee performance, workforce productivity, absenteeism and promotion patterns.

The project focused on preparing and analysing employee data, developing workforce KPIs, exploring factors affecting performance and building an interactive HR analytics dashboard.

## Dataset

The analysis used the **Employee Performance Dataset** from Kaggle.

The dataset contains employee demographic information, department details, salary, job level, performance ratings, promotion history, absenteeism and work location data.

## Data Preparation

The dataset was prepared before analysis to ensure consistency and accuracy.

Key preparation steps included:

- Reviewed data types and dataset structure
- Checked for missing values and inconsistencies
- Standardised fields for analysis
- Prepared employee, performance and workforce attributes for reporting
- Created calculated fields and measures required for the dashboard

## Analysis & KPIs

The dashboard uses calculated measures to monitor workforce performance.

**Key KPIs**

- Total Employees
- Average Performance Score
- Average Salary
- Average Absence Days
- Promotion Rate

**Analysis**

- Department wise performance
- Salary vs Performance
- Absence Days vs Performance
- Work Location productivity
- Job Level distribution
- Years at Company vs Promotion trends

## Interactive Dashboard

The Power BI report provides an interactive view of employee performance and workforce productivity.

The dashboard includes:

- Workforce KPI cards
- Department performance analysis
- Salary and performance analysis
- Absence and performance trends
- Work location productivity
- Job level distribution
- Promotion trends

Interactive filters allow users to explore the workforce across different employee and organisational attributes.

## Key Findings

**Department Performance**  
**Sales and Engineering** recorded the highest average performance score at **3.03**, while **Marketing** recorded the lowest at **2.95**.

**Work Location Productivity**  
**Remote employees** had the highest average performance score at **3.04**, compared with **3.01** for in-office and **2.97** for hybrid employees.

**Promotion & Absence**  
The workforce had a **14.46% promotion rate** and an average of **7.52 absence days**.

## Business Recommendations

1. **Improve lower performing departments**  
   Investigate the factors contributing to lower performance in Marketing.

2. **Evaluate work location practices**  
   Review practices used by higher performing remote teams and assess whether they can be applied elsewhere.

3. **Monitor absence and promotion patterns**  
   Use workforce trends to support targeted employee development and workforce planning.
